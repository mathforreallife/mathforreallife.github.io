Book sales from KDP

How to bring in your KDP numbers

KDP doesn't offer an API key, so the numbers come from KDP's own report file:

  1. On kdp.amazon.com, open Reports.
  2. Open Royalties (units sold, refunds and royalties) or Orders (paperbacks ordered), choose the dates, and download the report (the Download / Generate report button gives an Excel file).
  3. Click Import a KDP report above and pick that file.

Import as often as you like: a new import replaces the same dates, so nothing is counted twice. Royalties are KDP's estimates until Amazon pays them, and they stay in each store's own currency.

Tracking a link

Add ?src= and a name to any link you share, and the visits show up under “Traffic from your links”. For example https://mathforreallife.github.io/?src=pinterest or ?src=newsletter. Longer UTM tags (utm_source, utm_medium, utm_campaign) work too. Visits are counted without cookies or IP addresses.
